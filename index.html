Page2Excel Privacy Policy

Last updated: October 3, 2026

Page2Excel is a browser extension that allows users to select repeating content on a web page and export the extracted data to XLSX or CSV.

Data access and processing

Page2Excel accesses the content of the currently active web page only when the user explicitly initiates an action, such as selecting a block, detecting fields, preparing a table, or refreshing extracted data.

The extension processes selected page content locally in the user's browser for the purpose of providing its data extraction and export functionality.

Data storage

Page2Excel may temporarily store selected elements, detected fields, column settings, page URLs, and prepared table data in the browser's session storage so that the extension can preserve its working state while in use.

This temporary data is stored locally in the browser and is not stored on Page2Excel servers.

Data transmission

Page2Excel does not transmit extracted page content or prepared tables to the developer or to third parties.

Page2Excel does not use its own servers for processing extracted data.

Analytics and advertising

Page2Excel does not include third-party analytics, advertising systems, or tracking technologies.

Page2Excel does not sell user data or use extracted data for advertising, profiling, creditworthiness, or purposes unrelated to the extension's user-facing functionality.

Accounts

Page2Excel does not require a user account or registration.

Changes to this policy

This Privacy Policy may be updated if Page2Excel's functionality or data practices change. The current version will remain available on this page.

Contact

Политика конфиденциальности Page2Excel

Последнее обновление: 3 октября 2026 г.

Page2Excel - браузерное расширение, которое позволяет выбирать повторяющиеся данные на веб-странице и экспортировать их в XLSX или CSV.

Доступ к данным и их обработка

Page2Excel получает доступ к содержимому текущей веб-страницы только после явного действия пользователя, например выбора блока, определения полей, подготовки таблицы или обновления извлечённых данных.

Выбранные данные страницы обрабатываются локально в браузере пользователя исключительно для работы функций извлечения и экспорта данных.

Хранение данных

Page2Excel может временно сохранять выбранные элементы, определённые поля, настройки колонок, URL страницы и подготовленные данные таблицы в хранилище сессии браузера для сохранения рабочего состояния расширения.

Эти временные данные хранятся локально в браузере и не сохраняются на серверах Page2Excel.

Передача данных

Page2Excel не передаёт извлечённое содержимое страниц или подготовленные таблицы разработчику или третьим лицам.

Page2Excel не использует собственные серверы для обработки извлечённых данных.

Аналитика и реклама

Page2Excel не содержит сторонних систем аналитики, рекламы или технологий отслеживания.

Page2Excel не продаёт пользовательские данные и не использует извлечённые данные для рекламы, профилирования, оценки кредитоспособности или иных целей, не связанных с пользовательскими функциями расширения.

Учётные записи

Page2Excel не требует создания учётной записи или регистрации.

Изменения политики

Эта Политика конфиденциальности может обновляться при изменении функциональности Page2Excel или принципов обработки данных. Актуальная версия будет доступна на этой странице.
